Ускоритель kz-edge (Cloudflare Workers + D1, бесплатный тариф)

Зачем: страница и пакет данных отдаются за доли секунды из копии в Cloudflare; записи идут в Google как раньше.
Без связи приложение открывает последний сохранённый пакет (только просмотр).

Установка (один раз, на любом компьютере с Node.js 18+):
  1. install.cmd — вход в Cloudflare (браузер), адрес /exec, создание базы, публикация, ключ → CONNECT.txt
  2. В программе (WIZARD → Пароль → ⚡ Ускоритель) вставить адрес и ключ → Подключить.
  3. Раздать сотрудникам адрес ускорителя.
Обновление после новой версии: распаковать новый архив поверх старого (CONNECT.txt сохраняется) и запустить update.cmd — он пересобирает public, восстанавливает настройки и публикует Worker.

Как держится свежесть данных:
  - Apps Script перед каждой правкой WIZARD шлёт сигнал /edge/bump → кэш сбрасывается и перечитывается;
  - правки через сам ускоритель сбрасывают кэш сразу;
  - по завершении пересборки (загрузка 1С) данные перечитываются;
  - каждые 5 минут Worker сверяет подпись данных (kzwEdgeSig) с таблицей.

Файлы: src/index.js (Worker), wrangler.toml, public/ (собирается tools/build.mjs из app/), install.mjs.
Лимиты бесплатного тарифа: 100 000 запросов/день, D1 5 млн чтений/день — для десятков сотрудников с запасом.
