Обслуживание листов

Сверка ищет позиции, которые могут быть одним товаром под разными ключами: одинаковый артикул, одинаковое или очень похожее наименование, артикул одной позиции внутри наименования другой. Идентичный товар — позиции объединяются в группу замен с общим остатком (лист «Группы замен», «Аналоги», «Справочник»); разные товары — остаются раздельно и больше не предлагаются. Решения хранятся на листе «Сверка».

Как это работает

Движок сравнивает коды позиций склада (артикул, ключ, коды в наименовании) со строками базы Cross: если две позиции склада встречаются в одной строке базы или имеют общий код — они аналоги. Предложения: добавить в группу (одна из позиций уже в группе замен), новая группа (объединить впервые), проверить вручную (разные виды фильтров или связь с несколькими группами). Принятые предложения попадают на лист «Аналоги» под общей группой, в «Группы замен» и «Справочник»; остаток группы считается по всем складам в контроле. Справочно внизу — аналоги из базы, которых нет на складе.

Дашборд

Показатели и графики считаются из листа «Остатки» по выбранным типу и бренду: число позиций по статусам, дефицит, стоимость и количество в контроле (стоимость = остаток × средняя цена из 1С), группы замен в красной/жёлтой зоне. Графики: структура статусов, статусы по типам, остатки и стоимость по колонкам контроля (складам), топ брендов по стоимости и по числу красных позиций, динамика по загрузкам (лист «История»). WIZARD: «✎ Макет» — переставить, переименовать, скрыть блоки и изменить ширину (сохраняется для всех).

Выбор складов

Полоса «Склады» под шапкой — фильтр остатков для всего приложения. «Все склады» — как в таблице (сумма складов в контроле). Нажмите один или несколько складов (и при желании «Вне контроля») — на всех вкладках остатки, стоимость, статусы, дефицит, критический запас, бренды, группы замен (в т.ч. покрытие группой), статистика по товару и поступления по месяцам пересчитываются только по выбранным складам; столбцы невыбранных складов скрываются в таблицах приложения и при просмотре листов книги (Остатки, вкладки брендов, Критический запас, Сводка). Минимальный / критический запас сравнивается с остатком на выбранных складах. Выбор запоминается в браузере. «История» и «Сводка» в самой таблице считаются по всем складам.

Статистика по товару · поступления

Вкладка «Статистика» — поиск по встроенной базе (все позиции «Остатков»/«Справочника»: ключ, артикул, наименование, бренд). Клик по найденной позиции — карточка: остатки по складам, параметры контроля, партии на складе из выгрузки 1С (дата поступления, ТТН, поставщик, склад, количество, цена), графики поступлений по месяцам и цены по партиям, динамика остатка по загрузкам (приложение сохраняет снимок остатков при каждой новой выгрузке — лист «Снимки остатков»). Кнопка «Σ Сводно по найденным» считает то же по всем найденным позициям сразу — например по запросу «компрессор» или «сепаратор».

На дашборде блоки «Поступления по месяцам» строятся по датам партий из «Данных 1С»: выгрузка «Остатки по складам» содержит только партии, которые ещё лежат на складе, поэтому это динамика поступлений текущего запаса (проданные партии в неё не попадают). При выборе бренда все блоки, включая поступления и таблицу «Оборудование / запчасти / масла», считаются по этому бренду.

Остатки

Полный список учётных позиций (лист «Остатки») с раскраской по статусу. Фильтры: поиск, тип, бренд, статус, склад (где есть остаток), группа замен, только с остатком; сортировка кликом по заголовку; ⬇ CSV выгружает отфильтрованное. Клик по строке — карточка позиции: остаток этой позиции, общий остаток её группы замен и отдельно остатки всех других позиций группы (по складам, минимум, собственный статус), партии, цена и стоимость. То же окно открывается кликом на «Критическом запасе», «Сверке», «Аналогах», «Статистике» и в составе группы; в «Листах книги» клик по строке с ключом позиции (Остатки, Справочник, вкладки брендов, Критический запас, Аналоги…) показывает над таблицей блок «позиция / группа» с кнопкой «Карточка». WIZARD в карточке задаёт минимальный, критический и целевой запас, группу замен и комментарий — это пишется в «Справочник» (G, M, H, I, J), статус пересчитывается сразу. Кнопка «✎ Задать для отфильтрованных» записывает минимум / критический / целевой сразу всем позициям текущего фильтра (например всему бренду или всему столбцу).

Критический запас (столбец M «Справочника»): если задан — остаток ≤ критического даёт КРАСНЫЙ («ниже критического»), остаток ≤ минимального — ЖЁЛТЫЙ, выше — ОК. Если не задан — прежняя логика: ниже минимума КРАСНЫЙ, до минимума × (1 + порог %) ЖЁЛТЫЙ. Формулы статуса в «Остатках» приложение дописывает само после каждой пересборки.

Критический запас

Красные и жёлтые позиции, отсортированные по приоритету и дефициту. Колонка «К заказу» = целевой − остаток (если целевой задан) иначе минимум − остаток; «Сумма» — к заказу × средняя цена. ⬇ CSV — заявка на пополнение.

Заказ (песочница)

Вкладка «Заказ» собирает кандидатов на пополнение: по умолчанию красные и жёлтые позиции (можно: только красные, все с дефицитом до целевого, все позиции), фильтр по нескольким брендам сразу (выпадающий список с галочками), типу, поиску. В каждой строке — всё для решения: остаток на выбранных складах, минимум / критический / целевой, дефицит, рекомендуемое количество (до целевого, иначе до минимума), средняя цена и сумма, последнее поступление и поставщик последней партии, группа замен и её остаток, а также отметка «уже в заказе», если позиция есть в сохранённом заказе со статусом «согласован» или «отправлен поставщику». Позиции одной непокрытой группы замен показываются одной строкой группы: заказать нужно одну из них (выбирается в строке), а не все. Отмеченные строки попадают в корзину — там правятся количество и примечание, считается сумма; корзина хранится в браузере. ⬇ CSV / 📋 Копировать — заявка поставщику. WIZARD сохраняет корзину на лист «Заказы» и затем ведёт статус заказа (черновик → согласован → отправлен поставщику → получен / отменён); любой сохранённый заказ можно снова загрузить в корзину.

Исключения (снятые с производства, нерелевантные)

Позиция с заполненным столбцом N «Исключено» в «Справочнике» выводится из контроля: статус «— исключено», не попадает в красную/жёлтую зону, «Критический запас» и «Заказ», не даёт предупреждений. Переключатель «без исключённых» на полосе складов убирает их из «Остатков», «Брендов», дашборда и показателей (по умолчанию включён; выключите, чтобы увидеть всё). Остаток исключённой позиции по-прежнему учитывается в общем остатке её группы замен (товар физически есть и может покрывать потребность) и в стоимости склада. Исключить: поле «Исключено» в карточке, «✎ Задать для отфильтрованных» (например весь снятый модельный ряд одного бренда), кнопка ⊘ в строке «Заказа», «Исключить списком…» на вкладке «Исключения» (ключи или артикулы построчно). Вернуть в контроль — ↩ на вкладке «Исключения» или очистить поле.

Предупреждение о критическом остатке

При каждой загрузке данных приложение сравнивает список КРАСНЫХ позиций с тем, что вы уже видели в этом браузере. Появились новые красные — красная кнопка в шапке начинает пульсировать, выезжает окно со списком новых позиций (кнопки «Критический запас», «В заказ», «Понятно»), в заголовке вкладки браузера появляется «(N!)», и звучит короткий сигнал. 🔔 / 🔕 в шапке — включить / выключить звук (запоминается в браузере; браузер разрешает звук после первого клика на странице). «Понятно» помечает текущие красные как просмотренные; если позиция уйдёт из красной зоны и вернётся — предупреждение сработает снова. Красная кнопка с числом красных позиций видна всегда, пока они есть.

Ниже — таблица соответствия складов 1С колонкам контроля из листа «Настройки» (WIZARD меняет колонку и признак «Учитывать»; применяется при следующей пересборке).

Бренды

Как лист «Статистика брендов»: по каждому бренду / группе — позиций, с остатком, количество, стоимость и её доля, красных, жёлтых, ОК, без минимума, дефицит. Графики топ-10 по стоимости и по красным. Клик по бренду — его позиции в «Остатках».

Группы замен

Лист «Группы замен»: ID, назначение, минимум группы, остаток группы (сумма позиций в контроле), статус группы (тот же светофор, но по минимуму группы). Клик — состав группы. WIZARD: изменить назначение, минимум и комментарий, добавить позицию (поиск по ключу/названию) или убрать из группы, создать новую группу; «Аналоги → Справочник» — перенести группы, набранные на листе «Аналоги». После изменений состава групп для «Состава групп» и «Критического запаса» нужна пересборка («Обновить отчёты»).

История

Снимки статистики на момент каждой загрузки / пересборки: позиций, с остатком, количество и стоимость в контроле, красных / жёлтых / ОК / без минимума, дефицит — раздельно по типам и всего. Графики — динамика статусов и стоимости.

Загрузка 1С (WIZARD)

Выберите файл выгрузки «Остатки по складам» → «Загрузить и пересобрать»: файл уходит на Google Диск, конвертируется, строки записываются на «Данные 1С», дата и имя файла — в «Настройки», и в фоне запускается пересборка (стадии: ядро → вкладки брендов → отчёты → предложения аналогов). Ход виден в блоке «Состояние» и в баннере сверху; при нехватке времени скрипт сам продолжает через ~1 минуту. «Обновить отчёты» — пересборка без новой выгрузки; «Продолжить прерванную» / «Сбросить состояние» — как в меню таблицы. «Параметры контроля» — порог жёлтой зоны и минимум по умолчанию.

Сверка (дубли артикулов и наименований)

Программа сравнивает все позиции «Остатков» между собой: одинаковый артикул у разных ключей, одинаковое наименование, артикул одной позиции внутри наименования другой, очень похожие наименования одного бренда. Найденные связки показываются карточками; WIZARD отмечает «Это идентичный товар» — позиции объединяются в группу замен (общий остаток по складам, лист «Группы замен» / «Аналоги» / «Справочник» I) — или «Это разные товары» — позиции остаются раздельно, связка больше не предлагается (если до этого были объединены сверкой — разъединяются). В карточке можно снять галочки с лишних позиций перед объединением; состав получившейся группы потом правится на вкладке «Группы замен» (добавить / убрать позицию). Решения хранятся на листе «Сверка»; «⟳ Пересчитать сверку» — заново после загрузки 1С.

Аналоги (база Cross)

Лист «Cross замен фильтров» — база взаимозаменяемых артикулов (строка = артикул и его аналоги). WIZARD загружает базу прямо из приложения (CSV/XLSX с колонками «Артикул» и «Аналоги», либо формат самого листа); строки прежней базы заменяются, ручные строки сохраняются (есть галочка «заменить и ручные»). «⟳ Пересчитать» — движок сопоставляет позиции склада с базой и предлагает группы: добавить в группу, новая группа, проверить вручную. «Принять» — выбранные позиции попадают на лист «Аналоги» под общей группой, в «Группы замен» (остаток группы = сумма позиций в контроле) и в «Справочник»; «✕ не аналог» — предложение больше не показывается. При пересчёте WIZARD'ом обновляется и лист «Предложения аналогов» в таблице.

Листы книги · Конструктор

Плитки всех листов (служебные «Данные 1С», «Номенклатура», «Омонимы» скрыты по умолчанию — включаются в конструкторе). WIZARD: двойной клик по ячейке — правка; клик по ячейке — строка формул (fx) с полным текстом формулы или значения, Enter / «Сохранить» записывает, «Очистить» стирает; «=…» задаёт формулу; рядом — панель оформления и перемещение столбца (кроме листов, которые формирует скрипт), 📌 на плитке — кнопка листа в шапке, «+ Новый лист», «✎ Имя листа». Кнопки в шапке WIZARD переставляет перетаскиванием мышью (порядок сохраняется для всех пользователей). Конструктор — свои страницы из блоков (текст, ссылки, фрагмент листа, картинка, показатели), названия вкладок, шрифт по умолчанию, видимость листов.
